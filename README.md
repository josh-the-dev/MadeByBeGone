# MadeByBeGone

A simple World of Warcraft addon that removes the "Made by [crafter]" text from item tooltips.

## Installation

1. Download and extract to your AddOns folder:
   ```
   World of Warcraft\_retail_\Interface\AddOns\MadeByBeGone
   ```
2. Restart WoW or type `/reload` in-game

## Features

- Removes crafter name from crafted item tooltips
- Works with all tooltip types (GameTooltip, ItemRefTooltip, etc.)
- Supports all WoW client languages

## Requirements

- World of Warcraft Retail (11.0.5+)
